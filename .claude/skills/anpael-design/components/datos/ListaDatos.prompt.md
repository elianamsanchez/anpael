Ficha rotulo/valor: la forma en que ANPAEL muestra todo lo que se sabe de un animal o del sistema.

```jsx
<ListaDatos items={[{ rotulo: "Raza", valor: "Angus" }, { rotulo: "Animales", valor: "1.732", numerico: true }]} />
```

Rotulo gris 13px a la izquierda, valor semibold 14px a la derecha, filete entre renglones. El ultimo renglon no lleva filete.
