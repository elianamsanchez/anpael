Tarjeta blanca: el unico contenedor del producto; todo el contenido de una pantalla vive dentro de una o varias.

```jsx
<Tarjeta titulo="Corregir / completar datos" nota="Deja en blanco lo que no quieras cambiar.">
  ...
</Tarjeta>
```

Sin sombra: se separa del fondo de app (gris plano #F5F7F5) con un borde de 1px gris #D7DDD8 y radio 10px. Las tarjetas se apilan con 16px de separacion. `denso` para las que llevan tabla adentro.
