Casilla con etiqueta al lado; se usa para filtros del padron y para marcar una fecha como estimada.

```jsx
<Check etiqueta="Sin categoria" marcado={sinCategoria} onChange={...} />
```

La casilla usa `accent-color: var(--pasto-700)` (#47702F). La etiqueta va en gris 13px, no en el color del texto.
